# Data

Do not commit raw or processed datasets to Git.

This directory may track:

- dataset download or access instructions;
- official source URLs and license/access conditions;
- checksums;
- split definitions;
- small CSV, JSON, or YAML manifests;
- preparation and validation instructions.

For each dataset, document its name and version, provenance, expected local
directory structure, and exact preparation commands. Keep large files in an
approved local or shared storage location and reference that location without
including credentials.
