# Divergence Packet: 2026-08-28 outage observability and adaptive sensing

## Decision investigated

Can a low-cost edge-sensing FYP make a defensible, falsifiable contribution about **what an offline sensor record may honestly claim**, rather than merely implementing adaptive sampling, local buffering, or a dashboard?  This packet deliberately searches outside the current C3 timeout hypothesis.  It does **not** promote an existing candidate by default.

## Search boundary

Searches run on 2026-08-28: `adaptive sensing edge 2024 sampling`, `edge sensing outage sensor data`, `IoT offline data provenance sensor`, `sensor data completeness sequence numbers IoT`, `data gaps root cause IoT`, `edge sensor data completeness outage`, and exact-title/DOI searches for the sources below.  I read primary/official full text where accessible.  The most relevant recent primary systems are I-Canopy (2025) and UCC (2025); FarmBeats (2017), Comosum/FarmBIOS (2023), and Klier et al. (online 2024 / issue 2025) establish direct historical and methodological boundaries.

Excluded as poor directions: generic adaptive sampling/wakeup, sensor fusion, imputation, cloud reconciliation, and merely moving a familiar threshold to a Raspberry Pi.

## Top two formalizations

### S1: source-evidence label boundary

- [D] A scheduled sample opportunity is (j=(e,s,t)): boot epoch (e), source sequence (s), and scheduled time (t). The source emits a compact record (m_j=(e,s,w_s,q_s,h_b)), where (w_s) is its durable watermark, (q_s) a queue watermark, and (h_b) a batch identity. A gateway receives a subsequence (R). An independent logger captures a GPIO strobe for every attempted sample, producing (Z) only for evaluation.
- [A] The firmware implementation makes the strobe and persistent-state transition order explicit and tests it; the independent logger is not used by the deployed label policy. A durable watermark proves persistence only under a stated storage-fault model, not that the physical sensor value was correct.
- [T] For a pre-registered finite fault family (F=\{\text{Wi-Fi partition, gateway restart, source restart, queue overflow, injected storage-write failure}\}), the frozen rule has lower mislabelled-`complete` rate at equal `unknown` budget than receiver-only evidence, while consuming fewer bytes/joule than full raw duplication.
- Observable outcome: per interval, `complete / late-but-recoverable / unknown`; bytes, energy, labeling error against (Z), and decision delay.
- Counterexample: a source storage failure after a strobe but before watermark persistence can be observationally indistinguishable from an unrecoverable transport failure to the proposed schema. That interval must remain `unknown`.
- Negative-result value: a measured overlap/error matrix gives a defensible statement of which fault pairs this cheap metadata **cannot** separate; it prevents an invalid “continuous record” assertion.

### S2: receiver-only impossibility and the minimum extra observation

- [D] Let (Y) be all gateway-receivable state in an interval (arrival times, packet contents, receiver clock, and heartbeat status). Let (H_1) be “source samples and persists but the link is partitioned” and (H_2) be “source stops before sampling.”
- [A] The gateway does not observe source persistence, boot state, or an external physical trace during the interval.
- [T] There exist (H_1,H_2) with (P(Y\mid H_1)=P(Y\mid H_2)). Therefore no receiver-only decision (g(Y)) can reliably distinguish them. Adding a trusted source durable counter can distinguish these hypotheses under the narrower assumption that the counter/storage path works; it still cannot certify physical measurement correctness.
- Observable outcome: identical captured gateway traces under paired fault injections, then the reduction in ambiguity from each additional source field.
- Counterexample: authenticated, durable source state delivered after reconnection makes the two hypotheses distinguishable, so the result is a **boundary**, not a claim of universal impossibility.
- Negative-result value: converts “we need more telemetry” into a smallest necessary observation and an explicit non-identifiability statement.

## Decision

**HOLD.** S1/S2 form a coherent sensing-and-reliability **boundary** worth validation, not a locked research direction. S3-S5 are KILL; S6 is PIVOT/HOLD.  The most informative next experiment is the paired (H_1/H_2) trace test: if a timestamp/heartbeat baseline already separates the injected cases, kill S1/S2 immediately; if not, audit whether durable source counters/epochs are already standardized or published as the same exact claim.
