# Divergence Packet: 2026-08-31 Pi 5 RGB/NoIR adaptive optical sensing

## Decision investigated

**Decision under investigation:** given the confirmed Raspberry Pi 5B (8 GB RAM, 64 GB card), an official visible camera, an official NoIR camera, an IR illuminator and the required cable/adapter, find a non-personal benchtop workflow in which the node must choose a sensing action and the result has an independent physical oracle. The candidate family deliberately excludes biometrics, production service, safety actuation, and claims based only on a new detector or board deployment.

The current decision is not a thesis lock. The strongest residuals are (i) an empirical test of whether synthetic modality masks predict *physical* camera failure, and (ii) a bounded value-of-information experiment where a real IR pulse changes the observation before a known-label decision. Both remain Amber until the validation agent checks direct collisions and identifiability.

## Top two formalizations

### PHY-MASK (physical-failure transfer boundary)

- **[D] Data:** paired RGB/NoIR captures (x^{rgb},x^{nir}), camera/illumination state (m), physical failure cell (f), and an external known marker (y). Synthetic training corruptions (\tilde f) are zero/random masks or noise.
- **[A] Action:** (a\in\{\text{RGB},\text{NoIR+IR},\text{reacquire},\text{unknown}\}), under a fixed capture-time/energy budget.
- **[T] Target:** exact marker correctness, false-retain rate, abstention/reacquisition cost, and action ranking across held-out physical failure cells.
- **Observable outcome:** whether the marker decoded exactly and whether the policy's action was admissible; power and latency are measured locally.
- **Counterexample:** synthetic mask (\tilde f) and physical fault (f) can produce similar pixel statistics but different timing, ISP, saturation, or missing-frame behavior; a policy ordering learned on (\tilde f) can reverse on (f).
- **Negative-result value:** if rankings agree, it supplies evidence that this specific physical test is unnecessary; if they disagree, it identifies a reproducibility boundary for missing-modality papers. It cannot support a general field-fault guarantee.

### ASI-IR (active spectral value of information)

- **[D] Data:** low-cost preview (x_0), optional NoIR+IR capture (x_1), camera controls/metadata, measured power/latency, and a known printed code (y). Conditions are blocked by cover state, illumination, material and distance.
- **[A] Action:** choose no second capture, RGB second capture, or NoIR+IR pulse; output exact code or `unknown`.
- **[T] Target:** correct-code probability minus weighted capture cost at a preregistered budget; report the full cost-accuracy-abstention frontier.
- **Observable outcome:** exact code equality to the printed source, not model confidence or a human semantic label.
- **Counterexample:** if preview brightness/blur already determines the best action, or if IR only changes the same model confidence without changing code correctness, a simple threshold/fixed policy matches and the candidate is killed.
- **Negative-result value:** quantifies when adding NoIR/IR hardware has zero marginal value and prevents an unsupported RGB/NIR-fusion claim. A positive result is still only a bounded optical acquisition policy, not a global adaptive-sensing theorem.

## Queries and failed searches

- Searches for `Raspberry Pi 5 NoIR adaptive illumination research 2024 2025` returned product/documentation and project reports, but no primary paper with this exact hardware/action/known-code endpoint. This is a search gap, not evidence of novelty.
- Searches for `physical missing modality RGB NIR unplugged camera benchmark` found Liao et al. 2025 and related simulated benchmarks, but no verified paper using Pi RGB/NoIR cable/illumination faults with an external marker oracle. This remains [GAP] and must be checked by validation.
- Searches for `adaptive camera RGB NIR IR pulse value of information edge` found Lens, AdaptiveISP, AdaptiveAE, MadEye and multispectral fusion. Generic adaptive acquisition is therefore occupied; only the explicit physical action plus independent endpoint can survive.
- Event-camera, PTZ, LiDAR and thermal-camera candidates were rejected from this packet because the purchased hardware does not provide those modalities; importing them would create a board-availability rather than a research distinction.

## Decision

**HOLD (Amber), with PHY-MASK and FULL-CAP as the safest negative-result pivots.** ASI-IR and OPT-WIT are promising only as bounded physical value-of-information hypotheses; EV-EXPO is technically feasible but has a high AdaptiveAE/selective-sampling collision risk. No candidate is promoted to the canonical thesis state before an independent validation packet tests exact-claim overlap, simple baselines, timing/oracle validity, and whether the physical failure cells are actually distinguishable.

HOLD
