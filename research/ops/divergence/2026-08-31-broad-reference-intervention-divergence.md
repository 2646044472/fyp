# Divergence Packet: 2026-08-31 broad reference-intervention edge sensing

## Decision investigated

Can a one-year, low-cost, non-personal, non-production edge FYP be built around a local decision whose *additional physical reference observation* or *benign diagnostic intervention* changes what is identifiable? This packet deliberately excludes the already killed palm branch, passive virtual-sensor/wake cascades, generic sensor-health gates, generic test-time adaptation, vibration mounting, ToF, camera counting, and security challenge-response.

The result is not a direction lock. Two proposals are Amber HOLDs for validation: `PHT-2R`, which chooses an informative pair of calibration-buffer checks to distinguish pH slope from offset drift, and `LENS-RC`, which conditionally captures a fixed reference chart to distinguish scene change from camera/lens degradation before retaining a non-personal record. Three other candidates are useful collision controls or kills.

## Search boundary

Field map searched: (1) calibration-compensated thermal sensing and on-device uncertainty, (2) vision-sensor health and dirty-lens monitoring, (3) electrochemical pH/drift correction and calibration scheduling, (4) strain-gauge/load-cell metrology, and (5) passive versus pulse-excited battery sensing. Search date: 2026-08-31. Sources were primary papers, official proceedings, journal records, and official publisher pages; a preprint is explicitly marked as such.

Three audit cues apply to every non-killed candidate.

1. **Component collision:** adaptive calibration, uncertainty scores, dirty-lens restoration, camera-tamper detection, and active excitation each already exist.
2. **Exact-claim collision:** a candidate survives only if its actual object is a bounded local `accept / reference-check / unknown` decision with an independently measured witness, rather than another correction, classifier, restoration network, or board deployment.
3. **Boundary / impossibility:** a passive observation cannot distinguish two causes that generate the same observation. A claimed benefit must arise from the declared reference action, and not merely from training a larger model on labels that contain the answer.

## Top two formalizations

### PHT-2R: bounded two-reference calibration decision

- **[D] State/action:** At episode `t`, unknown sample truth is `z_t` and observed electrode voltage is `m_t = a_t*z_t + b_t + e_t`. Temperature and elapsed-time features form `h_t`. The local action is `u_t in {accept(r_t), unknown, check(q_t)}`, where a check exposes a known buffer `q_t` from a finite set and consumes one declared reference-use unit. The online controller never sees the hidden truth for a held-out unknown sample.
- **[A] Identifiability assumption:** During one short decision episode, `a_t` and `b_t` are stable; at least two buffer values differ; reference-buffer uncertainty and temperature are logged; the physical test can randomize drift/temperature/loading cells before the policy is frozen.
- **[T] Target empirical claim:** On held-out electrode x temperature x drift cells, at matched reference-use and unknown budgets, the policy reduces `Pr(abs(r_t-z_t)>epsilon AND u_t=accept)` relative to (i) no check, (ii) periodic one-buffer, (iii) periodic two-buffer, and (iv) uncertainty-only scheduling. Primary output is a three-axis frontier, not MAE alone.
- **Counterexample:** With one known buffer `q`, an observation constrains only `a*q+b`; any pair `(a,b)` sharing that value is observationally indistinguishable. If accepted sample classification depends on both gain and offset, no one-buffer policy can uniformly identify it. Conversely, if the observed drift is only an offset, the proposed separated-pair action is unnecessary and must lose to the simple baseline.
- **Negative-result value:** A preregistered map showing that ordinary low-cost probes exhibit effectively one-dimensional error under the intended conditions, or that fixed two-buffer checking dominates, is an honest boundary result: the physical extra action does not buy decision-relevant information in this cell set.
- **Bob Zhang relation:** [GAP] No specific public Bob Zhang paper was retrieved that is close to electrochemical metrology. The possible advisor fit is only generic sensor uncertainty/reliability; no named method is reused.

### LENS-RC: intervention-conditioned camera record validity

- **[D] State/action:** A primary frame is `y_t = F(scene_t, lens_t, camera_t) + e_t`; passive features are `p_t`. A chart capture produces `c_t = G(lens_t,camera_t,illumination_t)+eta_t` under a declared placement/exposure protocol. The local action is `u_t in {retain, chart, unknown}` with finite chart budget `B`.
- **[A] Witness assumption:** The chart is physically fixed, its capture can be separately labeled for lens/camera condition, and its illumination/exposure controls are strong enough that a chart capture changes evidence about sensor condition rather than merely repeats the scene.
- **[T] Target empirical claim:** With thresholds frozen before a held-out camera x lens-condition x scene/illumination block, chart-triggered routing has lower `Pr(record wrong AND retain)` at the same chart count and unknown rate than passive sharpness/quality, Ma-style clean-reference statistics, fixed-period chart capture, and always-chart capture.
- **Counterexample:** If a scene/lens pair generates the same `y_t` and the chart also fails to distinguish it, the physical action does not identify the cause. If passive features already yield the same frontier, the chart has no research value.
- **Negative-result value:** A finite condition map that identifies where reference charts fail (localized dirt, exposure coupling, focus changes) is useful sensor-health evidence. It prevents an unjustified claim that passive image quality proves record validity.
- **Bob Zhang relation:** [GAP] The closest broad fit is restoration/trustworthy vision, but no named Bob Zhang method has been retrieved and reused. It must not be represented as an advisor-overlap contribution.

## Pareto reading

`PHT-2R` has the clearest analytical boundary and cheapest independent truth, but it risks becoming routine calibration unless the query-identity test survives a direct-neighbor audit. `LENS-RC` has the fastest December demo and a visually legible story, but it has the strongest direct-neighbor risk from 2026 camera-health work and must prove the chart changes information rather than merely adds a quality score. `THERM-UQ-A` has strong science and a clear edge constraint, yet its central components are already occupied. `LOAD-RM` is physically easy but too close to generic reference allocation. `BATT-PULSE` has a real identifiability story but is directly crowded and creates an unnecessary safety boundary.

## Decision

**PIVOT.** Do not lock any new direction. Hand `PHT-2R` and `LENS-RC` to the validation role as Amber hypotheses only. Treat `THERM-UQ-A` as a control and `LOAD-RM`/`BATT-PULSE` as killed. The highest-value next gate is an exact-claim collision audit of `PHT-2R`: if two-buffer selection is standard or a generic calibration scheduler already contains the same action/endpoint, the remaining edge-sensing branch should not be protected by renaming it.
