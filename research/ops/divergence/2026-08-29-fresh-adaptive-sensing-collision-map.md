# Divergence Packet: 2026-08-29 Fresh Adaptive-Sensing Collision Map

## Decision investigated

Find a low-cost, non-personal-data edge-sensing FYP direction which makes a real local sensing decision and remains distinct from recent primary work.  This packet deliberately did **not** preserve any active candidate.  It tested five mechanisms that can superficially look like a new FYP: deciding whether to adapt a model, changing a sensor sample rate, diagnosing sensor health locally, switching context-specific local models, and physically challenging a potentially replayed sensor record.

All claimed innovation in this packet is **Amber**.  No global novelty claim is made.

## Search boundary

- Date searched: 2026-08-29.
- Constraints: a one-year FYP; runnable bench demo by 2026-12; expansion in 2027-H1; low-cost self-purchased hardware allowed; no personal data, production service, hazardous task, or safety actuation.
- Required story: a technician/operator records or inspects a *non-production benchtop* sensing result.  A false accepted result corrupts an experiment/maintenance record and wastes a later re-run or manual inspection; a false rejection wastes that same finite inspection budget.
- Excluded as merely a board/model/dataset swap: generic sentinel-to-wake policies, generic sensor fusion, model compression, camera count/abstention, vibration mount diagnosis, and generic local telemetry transfer.  Those are already active historical constraints.

## Top two formalizations

### F1: label-free adaptation gate

- **[D] Decision:** before a non-personal sensing model is used in a new physical configuration \(c\), the operator chooses \(a \in \{\mathrm{keep},\mathrm{adapt},\mathrm{calibrate}\}\).
- **[A] Action and cost:** `adapt` consumes local CPU/time; `calibrate` consumes \(k\) labelled reference trials; `keep` consumes neither.  The endpoint is a declared held-out fault/event error, not adaptation loss.
- **[T] Observable outcome:** source model, candidate adapted model(s), and an unlabeled target prefix \(X_c\).  The factual benefit \(\Delta_c\) requires labels held out from the decision.
- **[C] Candidate claim:** a source-trained gate \(g(X_c)\) can select an action with lower regret than `always keep`, `always adapt`, target confidence, target distance, and DAPPER on a predeclared finite set of device/condition cells.
- **Counterexample / kill:** Two target worlds can induce the same unlabeled \(X_c\) but different labels or adaptation benefit.  Thus no universal guarantee follows from \(X_c\); DAPPER already makes the same label-free performance-estimation decision in mobile sensing.  A result no better than DAPPER is a useful negative result but not a new mechanism.
- **Negative-result value:** a finite physical benchmark could document the failure of label-free adaptation selection under a stated condition block, but only as an evaluation/replication appendix unless it introduces a genuinely new, independently labelled observation.

### F2: alias-aware adaptive acoustic sampling

- **[D] Decision:** each segment, choose microphone rate \(r_t \in \{r_L,r_H\}\) and later retain `event / no-event / unknown` for a predefined non-personal sound class.
- **[A] Action and cost:** high rate consumes measured bytes/energy; low rate risks aliasing and task loss.
- **[T] Observable outcome:** local STFT/energy features at current rate; evaluation label and full-rate reference are withheld from the scheduler.
- **[C] Candidate claim:** an alias witness changes rate only when necessary and improves the energy--event-fidelity frontier over fixed rates.
- **Counterexample / kill:** at a rate below the required bandwidth, different high-frequency signals can produce the same sampled sequence.  A rate change/witness can expose some cases but EfficientMic already instantiates this exact single-mic, STFT, XGBoost, dynamic-rate response.  Failing to beat it is an honest negative result; beating it with a different dataset/rule is not yet a different research question.
- **Negative-result value:** measure which acoustic conditions evade an alias detector, but call it a finite failure map, not a general certificate.

## Decision

- **F1 — KILL.**  DAPPER occupies the exact label-free performance/adaptation-choice endpoint; SelfReplay further makes on-device sensory adaptation a direct baseline.
- **F2 — KILL.**  EfficientMic occupies the single-mic alias-aware adaptive-rate mechanism; the older spectrum method also removes the proposed witness component.
- **F3 — KILL.**  Zhiwei and CurrentSense make generic reference-free local sensor-health gating a direct neighbor, while common-mode changes retain an attribution counterexample.
- **F4 — KILL.**  CACTUS occupies context-triggered local micro-classifier selection under edge resources.
- **F5 — PIVOT / HOLD only.**  Active physical challenge/watermark is an established component.  It would require a new, carefully bounded threat/observation model plus full-text neighbor audit before it becomes a candidate.

**Overall: PIVOT.**  This round produced no candidate eligible for promotion.  The useful result is a collision map: changing an adaptive rule, board, benign sensing modality, or physical testbench does not suffice.  A next positive divergence round should search for a decision whose **observable evidence or action** is not any of (unlabeled adaptation estimation, adaptive sampling, cross-channel health gating, context model switching, or active watermarking), then hand that narrower decision to validation before entering `research/active/`.
