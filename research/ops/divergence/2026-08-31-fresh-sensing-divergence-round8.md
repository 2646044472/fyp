## Top two formalizations

### UWB-RL-CAUSE: reference links for bounded fault-cause attribution

- **[D] Decision:** for each target UWB range episode, output `retain`, `target-path ambiguous`, or `infrastructure-wide ambiguous`.  The output controls only lab-record annotation/diagnosis, never navigation or safety.
- **[A] Allowed action:** read target-link and fixed-reference-link UWB registers/CIR summaries and write one label.  No claimed range correction, no UWB--IMU fusion, no target re-training and no safety action.
- **[T] Target:** the episode-level root *category* defined before collection: either nominal, target-only path obstruction, reference/shared anchor-radio condition, or unresolved.  Truth derives from the deliberately applied fixture condition plus rail/tape position, not from the UWB policy.
- **Observable outcome:** (O=(q_t, q_{r1},...,q_{rk}, h)), where each (q) is the documented range/CIR/FQA/RSS summary and (h) is declared radio configuration.  The policy does not observe true time-of-flight error, hidden multipath geometry, or a universal fault cause.
- **Counterexample:** a sufficiently large metal object or RF disturbance may change target and reference links in the same way, while a reference-anchor hardware fault may affect only a subset.  Hence the links cannot identify an unrestricted causal taxonomy; furthermore, Peterseil et al.'s online link/node/system trustworthiness and Yang et al.'s error-source credibility classification are direct literature mechanisms.
- **Negative-result value:** a null result establishes that cheap reference links offer no incremental causal information beyond current UWB trustworthiness features for the named setup.  This can be a replication/benchmark appendix, not a thesis contribution.

### CSI-BaselineGate: an intentionally rejected Wi-Fi exact-neighbor test

- **[D] Decision:** retain a non-personal bench episode or mark it unknown after a CSI presence observation.
- **[A] Allowed action:** inspect target and optional auxiliary CSI streams and refresh a baseline; no personal activity inference, remote processing or adaptive classifier training.
- **[T] Target:** false retained episodes and unknown rate under time-blocked environmental changes, with a rail/switch truth source.
- **Observable outcome:** target and auxiliary CSI amplitude/phase features, packet count and quiet-period baseline age.
- **Counterexample / kill:** a change to the shared room/radios can change both links without exposing whether the target event is real.  More importantly, OpenCSI's per-link quiet-period Z-score, maturity tag and stale-baseline reliability already give the same monitored-baseline/abstain action family.  The candidate must therefore be killed unless validation finds a materially distinct observation/action/endpoint.
- **Negative-result value:** it would still demonstrate that a specific auxiliary link does not add information beyond an existing on-device self-calibration monitor.  That belongs in a protocol appendix, not an FYP thesis.
