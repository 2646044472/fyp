## Top two formalizations

### D1: condition-aware trustworthy ToF clearance

- **[D]** Episode state is `y in {clear, occupied}`. The edge node observes `x = (range_1:64, status_1:64, light, temperature, age, motion-summary)` and takes `a in {clear, uncertain/inspect}`. A false-clear loss `L_fc` is fixed above the inspection loss `L_i` before testing.
- **[A]** The held-out object-material/light/angle cells belong to a declared finite deployment family; observations across trials are not treated as independent frames when they share an object/setup.
- **[T]** A pre-frozen set-valued rule attains empirical false-clear rate no greater than `alpha` on each held-out family with fewer/equal inspections than the strongest simple rule. This is an empirical claim, not a distribution-free guarantee.
- **Observable outcome:** false-clear rate by held-out family, inspection rate, decision latency, camera duty (if a camera is used as verifier), and energy per episode.
- **Counterexample:** two target conditions yield the same observable ToF/status/light vector but opposite occupancy states. No local rule can distinguish them; it must abstain, add an observation, or accept risk.
- **Negative-result value:** a reproducible sensor-condition boundary map that shows simple `invalid => uncertain` is sufficient, or that no low-inspection trustworthy-clear claim is identifiable for this hardware family.

### D2: action-conditioned active self-test

- **[D]** Latent sensor state `f in {healthy, optical-obstruction, stale/frozen, offset, warm-up}`; scene state `y`; passive observation `x`; optional self-test result `r` from placing a known reference target. Actions are `clear`, `inspect`, or `self-test then clear/inspect`.
- **[A]** The reference-target response differs measurably between at least one actionable fault state and the healthy state at the same temperature/light conditions; the servo/test itself does not create unacceptable action delay.
- **[T]** Under a declared test-rate/joule budget, a risk-triggered self-test policy has lower false-safe action loss than passive residual/status and periodic testing on held-out fault-onset trials.
- **Observable outcome:** fault detection delay, false-safe / false-inspect rate, test frequency, incremental joules, and post-test decision correctness.
- **Counterexample:** the healthy scene and a faulted sensor produce the same `(x,r)` distribution. The fault is not identifiable with this test; no learning model can restore the claimed discrimination.
- **Negative-result value:** a clear failure-family boundary proving that active test hardware is unnecessary, insufficient, or only detects laboratory-induced faults.
