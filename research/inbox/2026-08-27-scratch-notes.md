显式区分 sensor health、环境/目标可观测性、任务可信度 与 residual observability，比永远融合、固定 fallback、quality-aware router 更能在同样的延迟、能耗和人工重试预算下，减少高风险自动决策。

最后那句“在同样的延迟、能耗和人工重试预算下”是在限制公平性：不能靠无限重拍、无限开全部传感器、无限运行大模型来换安全性。比较的是：在同样最多等待时间、最多能耗和最多允许用户重试次数下，哪种策略更少犯危险错误。

在真实、局部且相关的多传感器退化下，单一质量分数不足以安全选择系统动作；显式状态分离可改善任务风险与恢复成本的折中。

| 方向 | 它真正问的问题                                   |
| ---- | ------------------------------------------------ |
| S    | 系统为什么不可靠，以及下一步该做什么？           |
| T    | 多个 sensor 是否真的在看同一个时刻的同一件事？   |
| O    | 看到异常时，到底是环境变了，还是目标真的有缺陷？ |

S 最适合当前条件：它能直接使用实验室已有的 RGB/NIR/距离传感器，研究对象也是设备真实会发生的采集问题，同时有明确的反例和系统指标。

T 的研究味更强，但严重依赖硬件 telemetry。拿不到真实时序证据，就不建议做。

O 最容易在公开数据上起步，伦理和硬件门槛低，但和实验室已有方向、设备的结合较弱，而且新颖性最容易被已有 anomaly literature 挤掉。

当强光、反光材质、距离、运动、局部遮挡等同一个物理原因同时误导 RGB、NIR、ToF 时，多个传感器的“同意”是否只是虚假一致？系统能否识别这种情况，降低 false permit？
