# Edge FYP Research Workspace

This workspace is for selecting one defensible undergraduate FYP direction in edge computing. It is a research and decision workspace, not a thesis draft or an implementation repository.

## Start here

Read [active/README.md](active/README.md) first. It is the only current canonical state for the broad edge-direction search.

The prior edge sensing and palm-recognition investigation remains useful evidence, but it is historical. It must not silently constrain a new direction search.

## Research rule

active/ says what the project may currently claim. archive/ explains what was previously investigated and rejected. A direction stays HOLD until it has a bounded story, a precise claim, direct-neighbor audit, feasibility gate, and a valuable failure path.
