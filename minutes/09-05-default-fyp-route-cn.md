# 默认 FYP 路线：PRF-TR

**Date:** 2026-09-05  
**Status:** Default executable route; not a paper-novelty lock.

## 决定

在没有真实、可重复、非个人化工作流资产之前，默认推进 PRF-TR，而不再以
“edge-only + 可以购买硬件”为理由生成通用传感器、网络、RFID、掉电、调度或
监测项目。

这不是说相机必须存在，而是目前唯一经过直接邻居筛查后，仍有可执行的独立
真值、物理干预、动作后果和空结果路径的 FYP 备线恰好使用现有 Pi 与 Camera
NoIR v2。删除相机约束没有产生更强的研究对象。

## 要讲的故事

一名设施维护或实验室物料记录人员，需要把一次现场观察绑定到正确的非个人化
资产、监测点或样品编号。边缘节点在网络不可靠或无法即时求助时，只能：

1. retain：把本次读取写入本地记录；
2. reacquire：读取预先规定的第二张独立帧；
3. review：不自动绑定，交给固定人工流程。

错误 retain 会把观察写入错误历史；错误 reacquire 或 review 会产生额外时间、
能耗和人工成本。这个实验不声称识别维修完成、设备健康、人员身份或法律授权
状态。

## 研究问题

> 在固定 Camera NoIR v2、固定标记族和预先定义的成本下，数字注入的故障测试
> 是否会错误地选择在真实光学物理条件下的 retain / reacquire / review 动作？

物理真实标签来自冻结打印 payload 的独立扫描和预先指定的夹具条件；不能由
候选解码器、置信度或质量分数自行定义。

## 为什么它比新的 edge-only 故事更诚实

| 要件 | PRF-TR | 当前 edge-only 故事 |
| --- | --- | --- |
| 真实决定与后果 | 有固定绑定/重拍/复核账本 | 多数只剩平均准确率或吞吐量 |
| 独立真值 | 有精确 payload 与物理条件 | 常被同一传感器日志循环定义 |
| 可重复物理干预 | 光、反光、遮挡等固定 cell | 通常缺真实现场或只剩软件故障 |
| 基线 | 单拍、两拍、质量门、always-review | 往往被既有调度/恢复/读率方法覆盖 |
| 有效空结果 | 有 | 多数只能报一次 demo 或表格 |

## 贡献边界

允许的结果是一个有限、可复现的经验发现：在明确定义的设备、目标、物理条件和
动作成本中，数字测试挑出的动作是否在 held-out 物理条件下被固定两拍、标量门或
always-review 支配。

不允许的说法包括：新的 QR/ArUco 解码器、通用 synthetic-to-real 结论、通用
camera-health 机制，或关于澳门现场工作流已被部署的声称。

## 取代条件

只有当新的 edge-only 资产同时提供以下内容时，才取代 PRF-TR：

- 已存在的反复业务决定；
- 独立于候选系统的结果真值；
- 每周至少一次独立重复；
- 一个可记录或可随机化的因素；
- 通过直接邻居审计的、不同于普通工程实现的任务/动作/端点。

否则，继续推进 PRF-TR 的最小物理/数字动作审计，并把论文身份限定为 FYP
可靠性评估或严格空结果，而非新方法论文。

CONDITIONAL PASS: default FYP route; paper direction remains unlocked.
