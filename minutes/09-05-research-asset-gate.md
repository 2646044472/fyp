# Research Asset Gate for a Paper-Oriented Edge FYP

**Date:** 2026-09-05  
**Status:** Active decision gate. This is not a request to buy another camera.

## Why this gate exists

The completed audits repeatedly killed topics whose only distinction was:

```text
known technical task + Raspberry Pi + local application story
```

That combination can produce a strong engineering demo, but not a defensible
paper claim. A paper-oriented direction now needs an asset that changes the
observation model, task endpoint or evidence setting in a way that current
generic detector, scheduler, recovery, fusion or adaptive-acquisition papers
cannot reproduce.

## Minimum qualifying asset

At least one of the following must be available before a new positive paper
direction is promoted:

1. **Recurring real workflow:** a named role repeatedly makes the same
   non-personal decision, with permission to observe at least weekly and a
   documented outcome after the decision. A generic maintenance story is not
   enough.
2. **Independent physical truth:** a cheap instrument, controller trace,
   material assay, calibrated reference or deterministic source state measures
   the actual endpoint without reusing the candidate image score.
3. **Distinct physical intervention:** a controllable physical variable changes
   the observation in a way not reducible to brightness/blur/noise, and can be
   randomized or blocked across repeats.
4. **Legitimate data resource:** an accessible, permission-clear dataset with
   repeated episodes, outcome labels and metadata that expose a failure mode
   absent from standard public benchmarks.

The asset must be obtainable within the FYP window, ethical, non-personal and
safe. It must yield at least three independent collection sessions, rather than
many frames from one fixed scene.

## Assets that do not qualify by themselves

- another board, camera, sensor or radio;
- a larger neural network, VLM, model quantization or dashboard;
- a one-off photo collection without an independent outcome;
- a quality score, confidence threshold or synthetic corruption script;
- a Macao motivation without access to the workflow;
- a cheap sensor that measures only another ambiguous proxy.

## Historical lab-hardware note

An archived 2026-08-27 scratch note mentions laboratory RGB/NIR/distance
sensors. This is **not current resource confirmation**. More importantly, the
ideas attached to it -- cheap sentinel wake-up, common-cause fusion, and random
audits of no-wake intervals -- were separately audited and killed as generic
adaptive-sensing/selective-label/missing-modality mechanisms. Reopen nothing
from that note merely because the hardware is found; it would need a new,
documented workflow and an observation/outcome distinction that survives the
existing periodic-sampling and full-support-audit baselines.

## High-value information needed for a paper reset

The next viable positive direction should start with one concrete sentence of
the following form:

> A [role] at [accessible setting] makes [one recurring decision] at least
> [frequency]. A wrong decision causes [specific non-safety harm]. We can
> independently observe [outcome] using [instrument/log/material truth], and
> we can repeat or randomize [physical factor].

Until such a sentence is true, do not promise a paper. Choose PRF-TR only as a
bounded, technically rigorous FYP evaluation, not as a hidden method project.
