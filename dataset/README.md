# Palmprint dataset catalog

This directory contains documentation only. No images, videos, annotations, crops, templates, embeddings, participant records, or per-sample results are distributed here. Links point to dataset providers, release documentation, or original papers. A public paper, sample, or download page does not grant permission to redistribute the data. Follow the terms for the exact release you obtain.

## How to read the counts

- **Release** describes the publisher's collection unless a row explicitly says **local archive**. A **palm** is one distinct hand, not one person. A crop derived from a photo, or a second modality recorded in the same acquisition, does not add a visit.
- **FYP test pool** counts material reserved from training for the frozen **C E10** and **PalmBridge E10** recognizers. It includes both enrollment (the gallery) and query images. It is not a query denominator. Some protocols use only part of the pool; a planned query can also lack an image or fail region-of-interest (ROI) extraction.
- **Evaluation only** means the dataset was not a direct training source for these two recognizers. It does not establish that the ROI locator, earlier model selection, or pretraining never used it, or that its participants are independent of all training sources.

## Sources used for training and evaluation

Both frozen recognizers used the same six sources and the same **20,064 admitted images per epoch**. Their training candidate pools total **20,189 images**. The 125 candidates not admitted to training were **not** added to the test pools. The FYP subset may be smaller than the original release even before it is split. The available FYP splits (training candidates plus held-out originals or supplied crops) contain 16,000 MPD, 3,921 11K Hands, 1,173 BMPD, 910 SMPD, 1,933 BJTU PalmV2, and 1,017 X-Palm images. These totals describe the FYP input to the split, not the publisher’s full stock.

### Overlap and reporting limits

- **MPD and TCD are not independent sources.** Shen et al., [*Distribution alignment for cross-device palmprint recognition*](https://kaizhao.net/publications/pr2022distribution.pdf), §4 and Table 1, built CrossDevice-A from **310 palm identities shared by those source releases**. The exact overlap involving FYP's admitted MPD training images has not been audited here. TCD is not a separate training source for the frozen recognizers, but its full result should not be described as an identity-independent blind test.
- The headline Rank-1 results use **all planned queries** for the row. Where separately reported, the complete-enrollment result excludes only query attempts whose own palm lacked one or more of the five planned enrollment ROIs. Query-ROI failures still count for retained palms. The original gallery and rankings stay fixed; it is not a rerun or an equal-error-rate (EER) recalculation. Author-ROI and non-five-image protocols do not use that extra filter.
- Do not add an **ALL** row to its revisit or condition subset. For alternate gallery assignments, use the stated distinct-query count rather than adding denominators. Do not treat scored query counts as successful ROI counts. These are dataset roles and offline evaluation protocols, not new Raspberry Pi hardware validation or production results.

## Keep authorized data local

Development and synthetic tests do not require biometric datasets. If authorized to use a dataset, keep it outside the repository and pass its location through local configuration. Keep provider files read-only and put derived material in a separate local directory. If a local checkout must contain data, `dataset/local/` is ignored; do not bypass the ignore rules. Do not commit real examples, release archives, or participant-linked manifests for reproducing an evaluation.

For an authorized local evaluation, record the release, model version, train/gallery/query roles, acquisition conditions and denominators. Check participant disjointness across hands and sources before making a generalization claim. Only share aggregate results that the relevant terms permit.
