1接入既有辨識流程

沿用 Pi 的 FPN 掌區定位、C E10 特徵與範本比對，透過本機 HTTP 與 SSH 轉發連接付款後端。

2完成電腦登記

POS 提供客戶帳戶表單與嵌入式拍攝介面，後端指定匿名 ID，儲存範本後自動綁定。

3串接付款與帳本

後端計算訂單價格，建立付款意圖，檢查辨識結果、期限與餘額，在單一資料庫交易中結算。

4同步手機錢包

手機登入同一帳戶，以 WebSocket 更新餘額與收據，並提供模擬儲值。

5完成現場驗收

以真實手掌走完登記與購買，再測試未匹配、取消、斷線、刷新及重複請求。
