# Round 27 Palm-Only Reconciliation

## Summary

The project scope is locked to palmprint recognition. No Palm method is promoted. The strongest conditional question is `E-BOUND-X`: whether a cross-session enrollment decision changes a later untouched transaction when original eligible people, revisit burden and matched costs are preserved. If repeat visits are unavailable, the honest fallback is `OPEN-ACTION-EP/STAGE-NULL`, a negative identifiability audit. `VIS-GUIDE` remains a narrow physical completion/time evaluation; NIR missingness and full-path PAD remain gated.

## Findings

The Palm-only audit rejects generic ROI, retry, gallery calibration, matcher replacement, stage-risk, NIR fusion and PAD-method claims. The remaining distinctions are protocol-level and must be falsifiable: disjoint longitudinal visits, all-start episode linkage, a single counterbalanced prompt, or a physical attack that reaches the actual ROI and 1:N path.

The minimum next artifact is a frozen VIS executable trace for every eligible start through capture, ROI, open-set decision, unknown/correct/wrong identity, mock action and timing. This artifact is an engineering prerequisite and may support a later evaluation or negative result; it is not itself novelty.

## Insights

- Palm research should be organized around the observation and action boundary, not around another network architecture.
- Conditional enrollment claims are invalid if the confirmation visit is also the test visit or if successful enrollees are the only denominator.
- A physical NIR or PAI branch is not research-ready until the apparatus produces independent, repeatable observations and the full path is measured.

## Strongest objection

All surviving candidates may collapse to evaluation protocols already anticipated by biometric standards and direct Palm literature. If the MVP trace cannot support independent labels or if fixed controls dominate, the correct result is a bounded negative/feasibility report, not another Palm method search.

## Open questions

- Can the frozen Pi path record all eligible physical starts, including failures before a frame exists?
- Can three disjoint visits, consent, unknown participants and storage/deletion rules be obtained for `E-BOUND-X`?
- Does a single prompt factor change completion/time after fixture, ROI and matcher freeze?
- Is a repeatable paired VIS/NIR path or authorized physical PAI apparatus available later?
