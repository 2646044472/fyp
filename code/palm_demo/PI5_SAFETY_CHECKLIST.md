# 树莓派 5 使用注意事项

## 最重要的 8 条

1. 用 **5V / 5A USB-C 电源**，最好用官方 27W 电源。不要用来路不明的手机充电头。
2. 电源只能插标有 `POWER IN` 的 USB-C 口，**不要从 GPIO 针脚供电**。
3. 插拔相机排线、风扇、GPIO、SD 卡前：先执行 `sudo poweroff`，停机后拔掉 USB-C 电源。
4. 相机排线不要带电插拔，不要插反、歪插、折弯或压住。
5. 长时间跑相机或模型必须装风扇/散热器，不能挡住风扇进出风。
6. 板子要放在干燥、绝缘的桌面或 Pi 5 外壳里。远离水、金属、螺丝和饮料。
7. GPIO 是 **3.3V**，不能直接接 5V 信号、继电器、电机或大功率设备。
8. 不要直接拔电源关机，也不要通电时拔 SD 卡，否则容易坏系统或丢数据。

## USB-C 直连电脑时

- Pi 5 的 USB-C 口可在新系统里同时做供电和 USB 网络；要用支持**数据和供电**的 C-to-C 线，不要用只有充电功能的线。
- 初次测试先不要接相机，电脑 USB-C 口供电不足、Pi 反复重启或有低压提示时，立刻断开。改用官方 5V/5A 电源，并通过 Wi-Fi/网线 SSH。
- 不要把官方电源和电脑 USB-C 同时往同一个 USB-C 口供电，也不要带电插拔相机排线。

## 你新买的 NoIR 和红外补光

- RGB 相机与 NoIR 相机要当作两套不同采集条件，录入/验证时不要混用模板。
- Pi 5 可以接两台相机，但先逐台测试：`rpicam-hello --list` 查看编号，再用 `rpicam-hello --camera 编号 -t 0` 看画面。
- 红外补光灯不要直接接 GPIO 供电或由 GPIO 驱动；应使用它原本配套的电源/驱动模块。
- 红外光肉眼不明显，不代表没有风险。不要近距离直射眼睛，也不要在未确认规格时拆改补光板或提高供电电压。

## 接相机前

- Pi 已关机并拔掉 USB-C 电源。
- 轻轻打开 CSI 接口卡扣，排线插到底并保持平直，再扣紧卡扣。
- 确认相机板不会碰金属，排线不要急弯。
- 第一次开机后先运行：

```bash
rpicam-hello -t 0
```

没有画面、闻到焦味、板子异常烫或不断重启：立刻拔电，检查电源和相机排线方向。

## 日常开关机

开机：先接好相机和风扇，最后插 USB-C 电源。

关机：

```bash
sudo poweroff
```

等待 Pi 完全停止后，再拔 USB-C 电源。

## 第一次长时间运行时检查

```bash
vcgencmd measure_temp
vcgencmd get_throttled
```

- `get_throttled=0x0` 表示没有记录到低压或过热事件。
- 出现低压警告、频繁重启、USB 掉线或温度过高时，停止运行，优先检查电源、线材和散热。
