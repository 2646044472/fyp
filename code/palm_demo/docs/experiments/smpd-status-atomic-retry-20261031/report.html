SMPD v27 状态文件原子替换：有限重试修复

2026-10-31 · Windows · 仅操作层修复与小范围测试

已确认的故障

原运行提交第 216 条查询后，在发布下一次 query_inflight 状态时，os.replace(temp, status.json) 返回 PermissionError: [WinError 5] 拒绝访问。worker 退出码为 1，监督状态为 worker_stopped_no_restart。

事后检查时，状态文件可独占读写，报错临时文件已不存在，相关实验进程已退出。现有证据无法确定当时是哪一个进程或系统条件引发访问拒绝。此次修复没有验证或宣称故障根因。

修复行为

tools/smpd_run_journal.py 的通用 atomic() 保留同目录临时文件、完整 JSON 序列化、flush、fsync、关闭写句柄后调用 os.replace 的发布方式。

仅在替换操作抛出的异常带有 winerror == 5 时重试。总计最多 6 次尝试，依次等待 0.05、0.1、0.2、0.4、0.8 秒，累计退避上限 1.55 秒；操作系统调用自身耗时另计。各次尝试复用同一个已完整写入的临时文件。持续失败后抛出异常，并清理临时文件。没有原地截断写入或非原子发布回退。

独占记录在每次尝试前重复检查目标是否存在；这沿用原有单 runner 锁约束，不新增跨进程 compare-and-swap 保证。其他替换错误，以及序列化、写入、fsync 阶段的错误立即失败。永久访问拒绝也只会有限尝试后失败。
