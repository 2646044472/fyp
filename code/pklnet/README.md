# PKLNet
Palm keypoint localization neural network for touchless palmprint recognition
# How to use
## Requirements
- conda 4.9.0
- Anaconda 
- PyThorch 1.7.0
- Python 3.8.12
- GCC 7.5.0
- OpenCV (python)


## Test PKNet
```shell
cd path/to/PKLNet

# download 'net_params_500.pth' here.

conda activate xxx (depends on your python version)

# modify the test folder (`dataset_dir`) path in `test.py`

python test.py
```
> The ROI localization results will be stored at the current folder. (see folder `rst_test`)


## Train
```shell
# prepair the training data (image/label/keypoint) using the python version ROI localizaiton toolkit (PalmKit)

# modify the training folder (`dataset_dir`) path in `train.py`

cd path/to/PKLNet

conda activate xxx (depends on your python version)

python train.py
```
> The loss curves, feature maps, models will be stored at the current folder. (see folder `rst`)


# Files
In folder `lib`:
- datasets
    - loader
        - MyDataset.py (load image, background synthesis, gaussian blur, edge info) [uid, thumbUp; parse PalmKit keypoints]
        - MyTestDataset.py
    - toools
        - cv2_aug_transforms_palm.py (data augmentation: scale, rotation, color jitter, contrast, brightness, etc.)
    - data_loader_palm.py (dataset loader, transform, shuffle, num_workers, ...) 
- models
    - backbones
        - hrt
            - hrt_config_palm.py
            - hrt_backbone_palm.py
        - modules
            - transformer_block_palm.py
    - nets
        - dsntnn.py (hm loss)
        - pklnet.py (HRFormer, OCR, KCR, STN, dsntnn, loss functions)
- utils
    - lite.py (group weights)
    - show_PalmKit_Rst (load and draw the ROI locations generated by PalmKit)

In the root folder:
- train.py (batchsize, optimizer, loss function, loss curve, log info, checkpionts, input dataset; ROI shower & saver)
- test.py (input image set, load model, output roi & debug image & ROI shower)


Dataset:
- train
    - image
    - keypoint 
    - label
- test
    - image
    - keypoint
    - label
- your palm DB (a folder contains palm images for testing)
