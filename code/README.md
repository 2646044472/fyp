# Code

This directory will contain the project's runnable work, including:

- dataset acquisition and verification scripts;
- preprocessing and palm-region extraction;
- model training and evaluation;
- model export and optimization;
- device deployment and benchmarking;
- small configuration files required to reproduce runs.

The team will choose a package layout, dependency manager, and framework-specific
structure only after selecting a baseline model and target platform. Document
commands, dependency versions, inputs, outputs, and environment assumptions
next to each runnable component.

Do not commit model weights, exported models, generated results, secrets, or
local environments.
